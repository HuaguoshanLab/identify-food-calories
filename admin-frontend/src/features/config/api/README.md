# 运行配置 HTTP 合约

## 职责

`config/api/` 是模型服务摘要及文字运行策略请求、严格 Zod DTO 与安全错误分类的唯一所有者。页面只能使用这里导出的函数；不得直接 `fetch`、拼接后台 URL 或信任未校验响应。

## 允许依赖

- 可依赖 Zod、浏览器 `fetch` 和构建期验证的 `__ADMIN_API_BASE_URL__`。
- 调用方可瞬时传入内存 access token；本目录不得保存、记录或返回 token。
- 禁止依赖 React 组件、用户 H5、后端源码、数据库、Provider SDK、密钥或端点解析。
