# Docs

## 职责

`docs/` 保存面向开发者的中文教学、UI 合同和验收证据。当前事实以源码、测试、迁移及对应应用的 README/ARCHITECTURE 为准。本目录不保存密钥、令牌、邮件原文或用户数据。

## 允许依赖

- Markdown 链接到已提交的代码、README 和测试文件。
- 文档中的命令必须可在当前仓库结构中执行，并明确开发库与测试库边界。
- 禁止复制生产密钥、验证码、refresh token、原图/base64 或完整模型思维链。

新增普通源码文件时不更新本索引；只在上述稳定文档分区新增、删除或改变职责时更新。
