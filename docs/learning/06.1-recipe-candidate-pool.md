
### 具体菜谱选择验收（2026-09-12）

隔离测试库通过公开注册、登录和后台 API 准备合成数据，不代表真实目录含有这些菜品。真实 H5 输入“午餐换成验收清蒸鱼”，展示 650g/600g 两个候选且均未选中；调整输入禁用，确认按钮初始禁用。刷新后测试环境要求重新登录，登录后待选菜谱恢复。选择 600g 后只替换午餐，早餐和晚餐保持 650g；全天能量从 1950 更新为 1900 kcal，自动保存第 2 版。
