# 菜谱 CSV 导入填写说明

适用于后台「菜谱管理 → 下载模板／导入」。对应当前 11 列模板，核对日期：2026-09-17。推荐统一填写中文，保留列名与顺序。

## 字段说明

| 字段 | 填写要求与可选值 | 示例 |
|---|---|---|
| 关联目录菜品名称 | 必填，最多 200 字。必须唯一关联当前合格营养目录中的菜品，不会自动创建目录 | 白米饭 |
| 餐次 | 必填，单选：早餐、午餐、晚餐、加餐 | 午餐 |
| 单份克数 | 必填，纯数字，大于 0、不超过 2000，最多 6 位小数；不要附带 g 或“克” | 200 |
| 份量说明 | 必填，最多 120 字，说明一份的内容和重量口径 | 熟白米饭200g（可食部，不含额外配料） |
| 做法标签 | 必填，自由文本，没有固定枚举；1～20 个，多项用英文竖线分隔，每项不能为空 | 蒸制；多项示例：煎制\|炖煮 |
| 口味标签 | 必填，自由文本，没有固定枚举；1～20 个，多项用英文竖线分隔，每项不能为空 | 原味；多项示例：清淡\|咸鲜 |
| 状态 | 必填，只能填“待审核”或“已停用”，不能通过导入直接设为“已启用” | 待审核 |
| 配餐用途 | 单选，完整选项见下表 | 组合组成项 |
| 餐内角色 | 单选，完整选项见下表 | 主食 |
| 食材标签 | 可多选，只能使用下方 24 个标签，多项用英文竖线分隔，不得重复；未知可留空 | 米及制品 |
| 分类依据 | 填写分类时必填，最多 500 字，说明分类依据，不要臆测配料 | 白米饭以大米为主要食材，作为组合餐主食。 |

## 配餐用途

| 可选值 | 含义 |
|---|---|
| 整餐候选 | 可以作为一餐的独立候选 |
| 组合组成项 | 需要与其他食物搭配成一餐，例如白米饭、炒青菜 |
| 两者皆可 | 既可独立参选，也可作为组合餐的一部分 |
| 待确认 | 用途尚不明确 |

“整餐候选”表示配餐方式，不代表已经满足营养均衡要求，仍需通过计划校验。

## 餐内角色

| 可选值 | 填写参考 |
|---|---|
| 主食 | 米饭、馒头等 |
| 蛋白质菜 | 肉、鱼、蛋、豆腐类菜肴 |
| 蔬菜菜肴 | 蔬菜类菜肴 |
| 混合主餐 | 包含多种组成的主餐，如炒饭 |
| 水果 | 水果 |
| 奶及替代品 | 奶、酸奶及相应替代品 |
| 坚果种子 | 坚果、种子 |
| 汤羹 | 汤、羹 |
| 饮品 | 饮品 |
| 其他配菜 | 不适合归入以上角色的配菜 |
| 待确认 | 角色尚不明确 |

当前午晚餐组合逻辑使用“主食＋蛋白质菜＋蔬菜菜肴”；其他角色可以记录，但尚未全部接入组合搭配。用途或角色待确认的候选不参与当前自动配餐。

## 食材标签

下表分组仅用于阅读，实际填写具体标签，不填写分组名。

| 分组 | CSV 中可填写的标签 |
|---|---|
| 谷物、薯豆 | 米及制品、麦及制品、其他谷物、薯类、杂豆 |
| 动物性食材 | 畜肉、禽肉、鱼类、虾蟹贝类、蛋类、动物内脏 |
| 植物蛋白 | 大豆及豆制品、其他植物蛋白制品 |
| 蔬菜、菌藻 | 叶菜、花茎类、瓜茄类、根菜、菌菇、藻类 |
| 水果、奶、坚果等 | 水果、奶及奶制品、植物替代饮品、坚果、种子 |

例如银鱼炒蛋可填 `鱼类|蛋类`。食材标签不能填写“待确认”，不确定就留空；只填写有依据的类别。这些标签不是完整配料或过敏原清单。

## 文件与导入规则

- 使用 UTF-8 CSV，保留模板 11 列的名称和顺序，每次最多 500 条、1 MB。
- 后四列（配餐用途、餐内角色、食材标签、分类依据）可以全部留空，之后再补齐；只要填写其中任意一列，用途、角色和依据就必须填写，食材标签仍可留空。
- 同一文件中，同一目录菜品与同一餐次不能重复；不同餐次分行填写。
- 导入是新增候选，不是覆盖更新已有菜谱。导入完成后在后台审核、启用。
- 仍支持仅含前七列的无分类文件；旧八列角色模板已停用。
- 所有行通过校验后，填写导入原因再确认。CSV 中的“分类依据”与弹窗中的“导入原因”是不同字段。
- 餐次、状态、用途、角色和食材标签也接受代码中的英文枚举值；日常填写直接使用本文中文选项即可。

## 一道菜示例

以下内容包含表头和一条白米饭记录。保存为 UTF-8 的 `.csv` 文件即可用于导入预览；正式导入仍需满足当前目录关联条件。

```csv
关联目录菜品名称,餐次,单份克数,份量说明,做法标签,口味标签,状态,配餐用途,餐内角色,食材标签,分类依据
白米饭,午餐,200,熟白米饭200g（可食部，不含额外配料）,蒸制,原味,待审核,组合组成项,主食,米及制品,白米饭以大米为主要食材，作为组合餐主食。
```
