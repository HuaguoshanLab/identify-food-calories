# UI Docs

## 职责

`docs/ui/` 保存用户 H5 的跨阶段界面契约：页面壳、响应式、导航、滚动、安全区、组件边界和可访问性规则。它是后续 UI 实现的约束，不替代 `.planning/` 中的产品范围与阶段计划。

## 允许依赖

- 只定义项目已经采用的 React、Tailwind CSS、shadcn/ui Base UI 与 Lucide React 的使用规则。
- 只链接仓库内真实的组件、样式、测试和规划文件。
- 允许为未来功能定义稳定的布局接口；不得把未交付的 Agent、图片识别、记录或规划能力描述为已可用。
