# UI Docs

## 职责

`docs/ui/` 保存用户 H5 的共享界面契约：页面壳、响应式、导航、滚动、安全区、组件边界和可访问性规则。它约束 UI 实现；产品范围与业务规则见 [产品说明](../product.md)。

## 允许依赖

- 只定义项目已经采用的 React、Tailwind CSS、shadcn/ui Base UI 与 Lucide React 的使用规则。
- 只链接仓库内真实的组件、样式、测试和产品文档。
- 允许为未来功能定义稳定的布局接口；不得把未交付的 Agent、图片识别、记录或规划能力描述为已可用。

## 阅读顺序与命名

文件统一使用 `h5-<职责>.md`。先读设计规范，再按涉及的界面查阅实现记录。设计规范约束后续开发；实现记录中的测试结果只代表当时范围，不等于当前重新验收。

| [页面框架](h5-page-shell.md) | 固定页头、唯一滚动区、导航和安全区 |
