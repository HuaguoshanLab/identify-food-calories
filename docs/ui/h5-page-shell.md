# H5 页面框架落地记录

日期：2026-09-06。对应顺序第 3 项「页面框架」，不包含下一项公共组件改版。

## 实际变更

- 四 Tab 共享导航配置；页头固定在滚动区之外，使用设计稿图标与20px标题：分析这餐、饮食记录、饮食计划、我的。底部标签和本地路由保持不变。
- 详情页使用18px居中主标题与44×44px返回按钮，继续按真实浏览器历史返回。餐食详情沿用本地页面名称。清除分析、记录、计划、我的和记忆/餐食详情内容中的重复h1；字段、说明和动作保留。
- 每页一个主滚动区。切换pathname时主内容回到顶部、页头获得播报焦点；同页query/hash变化不重置滚动或焦点。非交互标题不画按钮式焦点环，交互控件与跳转入口保留焦点环。
- Tab页头主体56px、详情页头主体48px、导航主体64px，分别另外计入1px边框与对应安全区。通过flex占位，无需额外预留导航高度。
- 常规Tab内容左右28px，375px以下收至16px；详情左右16px。内容上边距16px；认证保留24px及原有标题/返回流程。无底部Tab的认证/详情内容增加底部安全区。
- 桌面宽度430px、高度100dvh减32px，32px外圆角、弱边框与主题轻阴影。宽屏不展开为桌面业务页面。

实现集中在 [layouts](../../frontend/src/layouts/README.md)；业务页面仅移交标题所有权。没有修改API、数据、认证逻辑、营养计算、模型调用、计划存档或表单提交规则。
