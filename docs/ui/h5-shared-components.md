# H5 共享组件

本文记录对应界面的实现与当时验证结果；当前共享设计要求见[H5 设计规范](h5-design-guidelines.md)。

2026-09-06。按设计稿 UI 与本地交互优先原则实施，不改 API、数据、校验或提交逻辑。

## 实现

- Button：默认文字与图标操作 44px，大号48px；8px圆角、森林绿主色、150ms颜色反馈。显式紧凑尺寸继续保留，页面调用方的尺寸覆盖不变。
- Input：默认44px高、16px文字、白底与12px水平内距，保留原生输入语义。
- Card：12px圆角、1px语义边框、轻阴影，标题16/24px半粗。
- Alert：6px圆角和12px内距，错误提示使用浅红底与清晰文字，原有role与内容不变。
- Badge：胶囊标签、最小24px高，允许长标签换行。
- AlertDialog：普通宽度上限360px、紧凑310px，左右至少16px；高度受动态视口限制，可滚动；操作按钮撑满。保留Base UI焦点管理、Escape与取消行为。
- Skeleton、业务空态和局部加载沿用现有实现与全局减少动态规则，未增加模拟状态。

## 验证

- 29个测试文件、167项测试通过；包含确认弹窗焦点限制、Escape、焦点返回与加载占位测试。
- 隔离 Playwright 响应式布局、滚动、键盘与导航测试1项通过。
- 类型检查和构建通过。已有构建大包提示保留。
- lint仍有原有两处错误：SafeProgressStages组件导出约束、weeklyReview仅用于类型的schema变量。
- 内置浏览器：我的→个人资料→删除确认→Escape取消；焦点先落取消，关闭后回到删除按钮，未删除资料。
- 320×740：弹窗宽288px、左距16px，两个按钮均44px，无水平溢出；资料编辑输入均16px/44px，取消编辑后未保存变更。
- 分析空输入提交仍显示“请先描述这餐吃了什么”，未发起模型分析。
- 未验证真机软键盘、非零安全区、200%缩放和深色主题；页面专属布局在后续步骤处理。
