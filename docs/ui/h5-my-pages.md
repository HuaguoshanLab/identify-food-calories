# H5 第5项：我的及详情页

## 实施范围

- 我的：AuthProvider真实邮箱、角色与账号状态组成头像图标摘要卡；4个现有入口置于单张分组卡，图标森林绿、弱分隔线与15px标题。
- 账号：只读白卡保留邮箱、状态、角色。
- 个人资料：摘要在375px及以上按4格基础资料、2格目标活动与完整目标速度展示；320px降为2列。编辑表单白卡化，保留所有字段、校验、保存与删除确认。
- 登录会话：12px圆角轻阴影卡片、13px日期；保留退出当前设备、其他会话撤销及真实空态/错误态。
- 偏好：保留原有列表与编辑路径，统一文字层次、卡片间距与字段容器；完整内容、来源与更新时间均保留。

## 设计取舍

仅参考设计稿UI。不复制昵称、模拟忌口、版本或模拟退出提示；退出操作仍在会话页。本次不增加首页资料与忌口数据查询，相关真实数据继续由各详情页管理，不改现有请求和缓存边界。

## 验证

- 29个测试文件167项通过；更新我的页真实身份摘要断言，原有4个链接和键盘可达性保持。
- 隔离Playwright响应式、唯一滚动区、键盘与导航测试1项通过。
- 类型检查与构建通过；原有大包提示保留。lint仍有SafeProgressStages、weeklyReview两处既有问题。

- 320px编辑资料、账号与偏好编辑均无横向溢出；桌面设备容器中检查了我的卡片、资料4格摘要。
