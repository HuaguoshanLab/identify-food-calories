# H5 森林绿主题落地记录

本文记录对应界面的实现与当时验证结果；当前共享设计要求见[H5 设计规范](h5-design-guidelines.md)。

版本：`h5-forest-v1`。日期：2026-09-06。

## 范围

运行时代码只修改 [styles.css](../../frontend/src/styles.css)。沿用现有语义类、组件、页面和数据，统一配色、系统中文字体、圆角、阴影及原生复选框/单选框强调色。桌面外底使用 `secondary`，设备容器内部继续使用 `background`。

本项不重排标题、不移动按钮、不新增环图、不修改表单逻辑。详情页重复标题、Tab 固定页头和各页信息密度留到页面框架及页面改版项；深色模式只保留 token，不新增开关。

## 实际样式

主色 `hsl(152 40% 30%)`、背景 `hsl(140 20% 97%)`、白色卡片、正文 `hsl(150 35% 12%)`、浅绿灰边框与设计稿一致。字体使用系统无衬线及 PingFang SC / Microsoft YaHei 等中文回退，不加载远程字体。保留正文和表单现有字号；基础圆角为 8px，派生 `rounded-md` 为 6px、`rounded-xl` 为 12px。

以下是相对设计稿的可读性调整，覆盖基座文档第 11 节对应的参考值：

| Token | 设计稿参考值 | 本项实际值 | 与白底对比度 |
|---|---|---|---|
| `muted-foreground` | `hsl(150 15% 45%)` | `hsl(150 15% 38%)` | 5.49:1 |
| `destructive` | `hsl(0 65% 50%)` | `hsl(0 65% 44%)` | 6.20:1 |
| `success` | `hsl(152 45% 38%)` | `hsl(152 45% 30%)` | 6.03:1 |
| `warning` | `hsl(22 80% 55%)` | `hsl(22 80% 36%)` | 5.92:1 |
| `info` | `hsl(205 70% 50%)` | `hsl(205 70% 36%)` | 6.09:1 |

主色与白色文字为 6.30:1；辅助文字在页面背景上为 5.17:1，在 `muted` 底上为 4.88:1，在 `accent` 底上为 4.55:1。以上按 sRGB 相对亮度计算，针对纯色 token 组合，不等于所有透明度、hover、禁用态及图表配色均已通过对比度验收。

阴影统一映射 `shadow-2xs` 至 `shadow-2xl`，采用设计稿绿灰色相与低透明度。营养素颜色注册为 `macro-protein`、`macro-fat`、`macro-carbs`，本项未新增图表或修改任何数值。
