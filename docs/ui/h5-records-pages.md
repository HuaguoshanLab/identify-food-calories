# H5 第6项：记录及餐食详情

## 实施

今日摄入使用36px主数值和15px单位；营养目标提示采用浅绿底。趋势、历史及周复盘分为白色12px圆角卡片，统一16px区块标题与13px辅助文字。七日SVG增加弱参考线、180px展示高度，保留真实数据表、键盘焦点和方向键。历史条目保留日期分组、餐次、时间、已保存状态、热量和详情链接，窄屏允许换行。

周复盘突出总能量，复用现有formatNutrition将Decimal显示为一位小数；后端精度、覆盖资格和安全状态不变。详情按菜品浅绿块组织营养快照，保留版本信息和时间。餐次/用餐时间编辑与删除操作分别置于卡片。

设计稿只参考UI：不迁入模拟记录、固定日期、图表库或示例复盘；本地历史链接、分页、时区确认与目标资格判断保持。

## 验证

- 29文件167项前端测试通过，包含时区gate、目标资格、历史分页、趋势键盘、复盘安全状态和编辑校验。
- 隔离Playwright响应式、滚动、键盘和导航测试1项通过。
- 类型与构建通过；原有大包提示和两处lint（SafeProgressStages、weeklyReview）保留。
- 内置浏览器：记录→真实餐食详情→编辑→删除确认→取消→两次返回列表；无数据修改/删除。
- 320px：记录文档与main均320px、数据表254px；编辑页无横向溢出；长英文菜名、版本信息能换行。
- 纯键盘Tab进入首个趋势点，ArrowRight将焦点移动到第二天；点击SVG点不保证获得键盘焦点，键盘路径已独立验证。
- 浏览器查看真实零餐今日状态、目标不可用和周复盘覆盖不足状态。未人为制造网络错误或新建餐食。
- 真机软键盘、非零安全区、200%缩放与深色模式仍未验收。

本项完成后停止，下一项是计划及历史页面。
