# Phase 06.1 Plan 04: 菜谱管理与可选加餐 UI Summary

后台新增了与营养目录同级的菜谱管理入口。管理员可以预校验 CSV、导入、下载模板、导出，并对当前页勾选的候选执行启用、停用或软删除；每次变更都要求填写原因并交由后端审计。用户端的计划标题不再假定永远只有三餐，可安全呈现后端返回的可选加餐。

## Delivered

- `/admin/recipes` 路由与“菜谱管理”侧栏入口。
- 严格 Zod DTO API 客户端：列表、导入预览/确认、模板/导出和批量生命周期操作。
- CSV 导入弹窗先显示逐行校验错误；所有行通过且填写原因前不能确认导入。
- 当前页全选、批量启用/停用/软删除及安全的 401/403/409 处理。
- H5 标题改为“今日饮食计划”；报告契约及餐次展示支持末位可选加餐。
- 菜谱 feature 自带弹窗组件，不依赖营养目录 feature 的内部组件。
