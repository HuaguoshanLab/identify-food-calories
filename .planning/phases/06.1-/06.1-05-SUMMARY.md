# Phase 06.1 Plan 05: 跨栈验收与教学 Summary

收口后台候选菜与用户餐单的目录关联。实现修复了一个真实阻断：后台审核发布的营养目录记录不在系统导入目录表中，原候选外键无法引用它，导致“发布目录后导入菜谱”返回 422。`0024` 令候选精确引用系统目录项或后台发布目录项之一，同时保留目录版本、名称和不复制营养的边界。

## Delivered

- 已发布且当前合格的后台营养目录可导入为菜谱候选；目录失格、候选停用或软删除都会立即从未来候选池排除。
- 用户最近三份已归档计划用于候选轮换：优先避开近期候选，候选不足时才回退；营养仍由确定性工具按单份克数重算。
- 计划 provenance 支持候选 revision 与目录版本，历史快照不受之后候选生命周期改变影响。
- 后台 Playwright E2E 覆盖真实注册、管理员提升、目录新建/审核/发布、候选 CSV 导入、批量启用/停用/删除。
- 新增中文教学文档和各模块 README 索引，说明目录边界、CSV 幂等审计、轮换、加餐和常见误区。
