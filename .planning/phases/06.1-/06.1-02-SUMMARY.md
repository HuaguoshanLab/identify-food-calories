# Phase 06.1 Plan 02: 候选菜管理 API Summary

管理员现在可以用中文 CSV 维护成品菜候选池。导入只接受唯一、合格且营养完整的既有目录菜；系统不会从菜谱自动创建营养目录。

## Task Commits

1. **Task 1: 候选 CSV RED 合同** — `0cdf5f2` (test)
2. **Task 2: 候选管理 API** — `30e53c6` (feat)

## Delivered

- `/api/v1/admin/recipe-candidates` 提供列表、模板、预览、导入、导出及批量 enable/disable/delete。
- 每次导入与批量状态变更重新读取当前数据库管理员角色，要求 `confirm`、非空原因、`Idempotency-Key`，并追加最小化审计差异。
- 导入在一个事务内进行：CSV 任意行不合法、目录名称不唯一、目录失格或营养字段不完整，均会回滚整批。
- 同一请求键的重放返回原结果；相同键但不同请求内容返回冲突。
