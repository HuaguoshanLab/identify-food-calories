<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser form → public auth API | 验证码和密码是非可信、敏感输入；前端只能显示受控错误分类。 |
| HttpOnly recovery context → React view | context 由服务器 Cookie 持有，UI 不得读取、复制或持久化。 |
| Route transition → focused DOM element | 新页面的可访问性焦点必须受组件控制，不能由历史或浏览器偶然状态决定。 |
| Browser verification → local account/session | 任何真实凭据提交改变本地认证状态，必须先取得用户确认。 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-01.1-26 | Information Disclosure | Auth error UI | mitigate | 仅按 API code 映射通用恢复文案；不显示 context、验证码、Cookie、request payload 或 stack。 |
| T-01.1-27 | Spoofing | Password recovery retries | mitigate | 终态仅接受 `RECOVERY_CONTEXT_INVALID`、`RECOVERY_CODE_EXPIRED`、`RECOVERY_ATTEMPTS_EXCEEDED`；所有成功仍由服务器 API 决定。 |
| T-01.1-28 | Tampering | Registration action state | mitigate | query 与 action context invalid 合并成单一 render 判断；verify/resend 两条回归测试防止状态遮蔽。 |
| T-01.1-29 | Denial of Service | Retry controls | mitigate | 复用 `formState.isSubmitting`，不添加循环重试、sleep 或客户端绕过冷却。 |
| T-01.1-30 | Elevation of Privilege | Protected route focus tests | accept | 只在既有 `RequireAuthentication` 后断言 DOM focus；不新增路由、角色或认证旁路。 |
| T-01.1-31 | Repudiation | Browser verification | mitigate | 凭据提交前取得用户确认，禁止撤销/退出会话，并在 SUMMARY 记录真实路径和未执行项。 |
| T-01.1-SC | Tampering | npm dependencies | accept | 此计划不安装或升级依赖。 |
</threat_model>
