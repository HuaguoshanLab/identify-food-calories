<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser URL → guarded route tree | 任意深链必须先经过身份恢复。 |
| Auth state → protected Outlet | 只有 authenticated 状态可渲染账号和会话页面。 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-01.1-18 | Elevation | `/app/*` route tree | mitigate (HIGH) | 单一 pathless guard 包住全部 index/Tab/detail 路由；逐路径未登录深链测试。 |
| T-01.1-19 | Spoofing | returnTo/deep link | mitigate (HIGH) | 共享 exact allow-list，登录后只回登记路径；非法目标回退 /app，再 replace 到 me。 |
| T-01.1-20 | Tampering | navigation history | mitigate | 只有 index/login completion 使用 replace；Tab 普通 push，并以 back history 测试固定。 |
| T-01.1-SC | Tampering | packages | accept | 本计划无安装/升级。 |
</threat_model>
