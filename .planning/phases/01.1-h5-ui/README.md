# Phase 01.1 — H5 UI 基座与现有页面迁移

## 职责

本目录保存插入阶段 01.1 的讨论、设计、计划、执行总结与验收证据。阶段目标是在 Agent 核心开发前统一用户 H5 的页面壳、四 Tab 目标信息架构、滚动、安全区、语义 token，并迁移 Phase 1 已交付页面。

## 允许依赖

- 以 `docs/ui/h5-foundation.md` 为跨阶段 UI 基座合同。
- 读取 Phase 1 的 UI 规格、认证页面、测试与 UAT 作为回归基线。
- 只规划 `frontend/` 用户 H5；不得修改后端业务协议，不得提前实现 Agent、记录、计划或后台功能。
