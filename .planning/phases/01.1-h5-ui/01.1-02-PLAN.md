<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Router state → active navigation | URL 决定当前 Tab 与可见页面层级。 |
| Viewport/safe area → interactive UI | 浏览器尺寸和 inset 可能遮挡关键操作。 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-01.1-03 | Spoofing | BottomNavigation | mitigate | 只从受控 routePaths 建立真实 NavLink，使用 aria-current，不手写不一致 active 状态。 |
| T-01.1-04 | Denial of Service | MobileFrame / PageScrollArea | mitigate | 单滚动所有权、min-height:0、safe-area 和 320px 测试防止操作被遮挡或页面不可用。 |
| T-01.1-05 | Elevation | DetailLayout | mitigate | 详情壳只提供导航，不建立权限真相；实际路由仍必须在统一认证守卫下接线。 |
| T-01.1-SC | Tampering | package registry | accept | 不安装新依赖；Lucide、Router 和 shadcn 已锁定。 |
</threat_model>
