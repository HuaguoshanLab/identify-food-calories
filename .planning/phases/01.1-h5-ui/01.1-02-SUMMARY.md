# Phase 01.1 Plan 02: H5 页面壳与四 Tab 导航 Summary

**建立统一 H5 设备外壳、单滚动主区域、无 Tab 的公开/详情布局，以及由真实路由驱动的四项底部导航。**

## Performance

- **Duration:** 5 min
- **Tasks:** 3
- **Files modified:** 10

## Accomplishments

- `MobileFrame` 集中拥有 `100dvh`、flex 列布局与裁剪边界；桌面仅增加 430px 设备外框，不改变内部 H5 内容模型。
- `PageScrollArea` 是唯一的 `<main>` 与纵向滚动区，使用 `flex-1 min-h-0 overflow-y-auto` 防止内容挤压固定 sibling。
- 认证页以品牌入口或明确的 `backTo` 返回链接呈现；详情页固定返回 `/app/me`，两者都不显示底部 Tab。
- `AppShell` 使用跳到主要内容链接与路由驱动的四个真实 `NavLink`：分析、记录、计划、我的；普通 Tab 跳转保留浏览器历史。

## Decisions Made

- H5 内容与顶部/底部框架使用同一个 `MobileFrame`，不在业务页重新声明全屏高度或滚动容器。
- Tab 当前态由 React Router 的 `NavLink` 产生 `aria-current="page"`，避免本地状态与 URL 脱节。
- 直接深链没有历史记录时，认证步骤仍能回到 `/register`、`/forgot-password` 等已知路径；详情始终回到“我的”。
