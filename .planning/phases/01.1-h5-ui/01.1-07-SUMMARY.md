# Phase 01.1 Plan 07: H5 路由整合与身份边界 Summary

**将公开页、认证步骤、四个 Tab 和账号详情接入单一、可刷新且安全的 H5 嵌套路由树。**

## Performance

- **Duration:** 8 min
- **Tasks:** 3/3
- **Files modified:** 9

## Accomplishments

- 统一 pathless `RequireAuthentication` 恢复 bootstrap/identity-error/unauthenticated/authenticated 四态；认证成功后只渲染 `Outlet`，所有 `/app/*` 深链共享精确 `returnTo`。
- `/app` 使用 replace 到 `/app/me`；分析、记录、计划、我的均位于 `AppShell`，账号资料与登录会话位于无底部导航的 `DetailLayout`。
- 公开入口、认证入口和两个步骤页分别进入 `PublicAuthLayout`；邮箱验证固定返回注册，重置密码固定返回找回密码。认证内容移除了重复 viewport/main 与旧色值工具类。

## Decisions Made

- 精确 returnTo 白名单继续由 `routePaths.ts` 和 `returnTo.ts` 共同定义；非法地址先回 `/app`，再由 index replace 到 `/app/me`。
- 详情页返回目标保持确定的 `/app/me`，不能依赖可能为空的浏览器历史；Tab 则保留默认 push 语义。
- 公开认证表单只提供内容，`PublicAuthLayout` 持有唯一 viewport、header 和 main scroll area，避免嵌套地标及手机端滚动冲突。
