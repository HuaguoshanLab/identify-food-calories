## Browser Verification

- **浏览器与公开服务：** 使用 Codex 内置浏览器 `iab`，真实页面为 `http://127.0.0.1:5173`，验证码只从公开 Mailpit HTTP `http://127.0.0.1:8025/api/v1/messages` 读取。
- **启动前状态：** 5173/8000 没有监听；`postgres`、`postgres-test`、`mailpit` 已运行且健康，因此仅调用 `docker compose up -d --wait` 确认 readiness，未停止这些预先存在的服务。
- **本任务拥有的进程：** 根任务为最终复核启动 FastAPI PID `49316`（8000）和 Vite session `82512`（5173）；三个 readiness URL（API health、Mailpit、H5）成功后开始浏览器交互。验收结束后两者均已停止。
- **真实路径：** `/` → 注册 `h5-browser@example.test` → 读取 6 位 Mailpit 验证码 → 验证 → 登录 → 分析/记录/计划/我的四个 Tab → 账号资料 → 登录会话 → 第二设备真实登录 → 撤销确认 → 退出当前设备。
- **关键观察：** 分析、记录、计划各仅显示标题和“功能即将开放”；“我的”页有且仅有“账号资料”“登录会话”两个入口；账号页展示邮箱、正常、普通用户且没有底部 Tab。会话开始只有当前设备，第二设备登录后出现远端会话；确认撤销后显示“登录会话已撤销。”并回到“暂无其他登录会话”。退出后到 `/login?returnTo=%2Fapp%2Fme%2Fsessions`，后退仍在 `/login?returnTo=%2Fapp%2Fme`，未显示受保护内容。
- **错误/空态与控制台：** 真实观察了“暂无其他登录会话”空态。期间发现 Base UI CTA 因将导航 Link 作为 Button 子节点产生控制台警告；修正后首页为两个普通 Router Link（创建账号、登录），`tab.dev.logs({error,warning})` 为空。
- **未覆盖：** 本阶段不上传图片，也不执行未来的分析业务；本地开发库保留由真实注册创建的测试账号，未通过直接删库、token 复制或伪造步骤清理。
