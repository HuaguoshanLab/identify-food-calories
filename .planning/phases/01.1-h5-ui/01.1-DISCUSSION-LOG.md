## 未交付 Tab 的呈现与路由

### 登录后的默认 Tab

| Option | Description | Selected |
|---|---|---|
| 我的 | 当前唯一真实功能；Phase 2 再切换默认入口 | ✓ |
| 分析 | 立即符合最终顺序，但登录后首先看到占位页 | |
| 记住上次 Tab | 增加跨会话状态管理 | |

### 未开放页面内容

| Option | Description | Selected |
|---|---|---|
| 标题 + 状态说明 | 显示页面标题与“功能即将开放”，不放假功能 | ✓ |
| 只显示页面名称 | 最小占位，但状态不明确 | |
| 标题 + 功能介绍 | 描述未来能力，文案更重 | |

### Tab 路由

| Option | Description | Selected |
|---|---|---|
| 独立路径 | 四个 Tab 各有 URL，可刷新恢复 | ✓ |
| `/app` + 查询参数 | 用 query 表达当前 Tab | |
| 组件状态 | URL 不变，刷新丢失 Tab | |

### 返回键行为

| Option | Description | Selected |
|---|---|---|
| 按访问顺序返回 | 保留普通网页历史行为 | ✓ |
| Tab 切换不进历史 | 返回直接离开当前 App 路径 | |
| 只保留最近 Tab | 折中但不直观 | |

**User's choice:** 展示四个 Tab；未开放页面显示标题与明确状态；独立路径；正常浏览器历史；Phase 01.1 默认进入“我的”。

## 首页与认证页统一

### 首页主操作

| Option | Description | Selected |
|---|---|---|
| 创建账号 | 主按钮；登录为次级按钮 | ✓ |
| 登录 | 优先已有用户 | |
| 两个同等级按钮 | 无明确视觉优先级 | |

### 认证页顶部

| Option | Description | Selected |
|---|---|---|
| 按流程区分 | 入口页显示品牌，后续步骤显示返回 | ✓ |
| 全部品牌入口 | 后续步骤返回不方便 | |
| 全部返回按钮 | 深链进入可能没有有效上一页 | |

### 多步骤进度

| Option | Description | Selected |
|---|---|---|
| 简洁文字进度 | 使用“步骤 1/2、步骤 2/2” | ✓ |
| 进度条 | 对两步流程视觉过重 | |
| 不显示 | 用户不知道还需几步 | |

### 反馈层级

| Option | Description | Selected |
|---|---|---|
| 按错误层级展示 | 字段、页面、成功跳转分别反馈 | ✓ |
| 全部 Toast | 字段错误难定位 | |
| 全部顶部提示 | 用户仍需查找错误字段 | |

**User's choice:** 全部公开与认证页面统一；保持当前首页创建账号/登录的主次关系；流程顶部和反馈按上下文处理。

## 我的页面信息结构

### 根页面入口

| Option | Description | Selected |
|---|---|---|
| 纵向设置列表 | 图标、标题、说明与箭头 | ✓ |
| 两张卡片 | 对简单入口偏重 | |
| 两列宫格 | 说明和可访问性较弱 | |

### 账号资料

| Option | Description | Selected |
|---|---|---|
| 只读资料 | 邮箱、状态、角色，不伪造编辑 | ✓ |
| 只显示邮箱 | 信息不足 | |
| 加入编辑入口 | 超出当前 API 和阶段范围 | |

### 登录会话

| Option | Description | Selected |
|---|---|---|
| 列表直接操作 | 保留退出、撤销与确认弹窗 | ✓ |
| 单会话详情页 | 页面层级更深且信息不足 | |
| 只读列表 | 破坏 Phase 1 已交付能力 | |

### 详情页导航

| Option | Description | Selected |
|---|---|---|
| 隐藏底部 Tab | 顶部返回，聚焦详情任务 | ✓ |
| 保留底部 Tab | 根页面与详情层级混淆 | |
| 仅会话页隐藏 | 行为不一致 | |

**User's choice:** “我的”只放两个设置列表入口；账号只读；会话保留真实操作；详情页隐藏底部导航。

## UI 验收深度

### 截图视口

| Option | Description | Selected |
|---|---|---|
| 关键视口 | 430px 截图，320px 与桌面做布局检查 | ✓ |
| 全视口截图 | 覆盖高但重复和误报多 | |
| 只截桌面 | 不能证明真实 H5 | |

### 基线页面

| Option | Description | Selected |
|---|---|---|
| 代表性页面 | 覆盖页面壳、表单、详情和弹窗 | ✓ |
| 每条路由 | 共享布局产生大量重复基线 | |
| 只截页面壳 | 认证和会话回归不足 | |

### 数据来源

| Option | Description | Selected |
|---|---|---|
| 真实后端与公开 API | Mailpit 完成真实认证和会话路径 | ✓ |
| 全部 MSW | 无法证明跨栈链路 | |
| 截图 MSW、人工真实 | 两套状态可能漂移 | |

### 基线更新

| Option | Description | Selected |
|---|---|---|
| 人工审查后更新 | 先确认差异属于预期变化 | ✓ |
| 自动更新 | 可能覆盖真实回归 | |
| 不提交截图 | 无持续回归门禁 | |

**User's choice:** 采用有代表性的 430px Git 截图基线；真实跨栈验收；所有基线变化必须人工确认。
