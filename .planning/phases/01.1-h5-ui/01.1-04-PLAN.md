| Boundary | Description |
|---|---|
| Session API data → DOM/action target | 服务端 session id 和 current 标志决定破坏性操作目标。 |
| User confirmation → DELETE request | 用户意图跨入撤销副作用。 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-01.1-09 | Elevation | remote session revoke | mitigate (HIGH) | 只使用当前用户查询返回的 id，保留后端用户域校验；当前 session 不走 remote DELETE；测试请求目标和动作隔离。 |
| T-01.1-10 | Repudiation | revoke feedback | mitigate | 确认弹窗、pending 防重、成功状态播报和 Query 刷新让用户意图与结果可观察。 |
| T-01.1-11 | Information Disclosure | session cards | mitigate | 只展示既有公开响应字段，不显示 token/cookie/session digest；测试不记录敏感值。 |
| T-01.1-SC | Tampering | dependencies | accept | 不安装新包，使用已审核 AlertDialog/Query。 |
</threat_model>
