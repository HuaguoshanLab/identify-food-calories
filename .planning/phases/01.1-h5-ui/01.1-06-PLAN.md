<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Form input → public auth API | 邮箱、密码、验证码等未可信输入进入认证协议。 |
| HttpOnly cookies → browser auth lifecycle | refresh/recovery context 不得被 React 读取或复制。 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-01.1-15 | Information Disclosure | auth forms | mitigate (HIGH) | 保留非枚举错误；不记录/持久化密码、验证码、token、recovery context；测试 payload 与 storage 禁用。 |
| T-01.1-16 | Spoofing | verification/reset flows | mitigate (HIGH) | 保留服务端 context、冷却、尝试限制和 terminal 错误；UI 不本地伪造成功或 session。 |
| T-01.1-17 | Denial of Service | submit/resend | mitigate | pending 禁用重复提交、服务器 cooldown 倒计时与显式恢复链接，禁止固定 sleep。 |
| T-01.1-SC | Tampering | dependencies | accept | 不安装依赖或重建 shadcn 原语。 |
</threat_model>
