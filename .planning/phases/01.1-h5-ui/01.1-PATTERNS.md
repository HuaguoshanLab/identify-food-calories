## Pattern Assignments

### Route tree: `frontend/src/App.tsx`

**Analog:** current `frontend/src/App.tsx`

**Current declarative route-table pattern** (`frontend/src/App.tsx:15-28`):

```tsx
export function App() {
  return (
    <Routes>
      <Route path="/" element={<LandingPage />} />
      <Route path="/login" element={<LoginPage />} />
      // ...public routes...
      <Route path="/app" element={<RequireAuthentication><AccountAndSessionsPage /></RequireAuthentication>} />
      <Route path="*" element={<LandingPage />} />
    </Routes>
  )
}
```

**Copy:** keep `App` as a pure route table. Replace the single protected element with one pathless `RequireAuthentication` route whose children render through `<Outlet />`; inside `/app`, use an index `<Navigate replace to="/app/me" />`, an `AppShell` layout for the four Tab roots, and two `DetailLayout` pages outside `AppShell`.

**Do not copy:** per-page wrapper composition or query-param tabs. Only the `/app` index redirect uses `replace`; `NavLink` Tab clicks must push normal history.

### Route constants and safe return: `frontend/src/routePaths.ts`, `frontend/src/auth/returnTo.ts`

**Analog:** `frontend/src/auth/returnTo.ts`

**Security pattern** (`frontend/src/auth/returnTo.ts:8-30`):

```ts
export function parseReturnTo(candidate: string | null | undefined) {
  if (!candidate || !candidate.startsWith('/') || candidate.startsWith('//') || candidate.includes('\\')) {
    return '/app'
  }

  try {
    const parsed = new URL(candidate, 'http://food-agent.local')
    if (
      parsed.origin !== 'http://food-agent.local' ||
      parsed.hash ||
      !protectedRoutePaths.has(parsed.pathname)
    ) {
      return '/app'
    }
    return `${parsed.pathname}${parsed.search}`
  } catch {
    return '/app'
  }
}
```

**Copy:** retain origin, protocol-relative URL, backslash and hash rejection. Move only the path strings to a React-free leaf module and exact-allow-list `/app`, the four Tab paths, and the two detail paths.

**Pitfall:** never replace the set with `pathname.startsWith('/app')`; that widens the redirect surface to unregistered/future routes. Login completion must retain `navigate(parseReturnTo(...), { replace: true })` from `LoginPage.tsx:43-52` so the login page leaves history without erasing later Tab history.

### Shared H5 layouts: `frontend/src/layouts/*`

**Closest analog:** `frontend/src/auth/PublicPages.tsx:10-32`

**Existing composition/focus pattern:** 

```tsx
function PublicPage({ children, description, title }: PublicPageProps) {
  const headingRef = useRef<HTMLHeadingElement>(null)

  useEffect(() => {
    headingRef.current?.focus()
  }, [])

  return (
    <main className="min-h-dvh px-4 py-8 md:px-6">
      <div className="mx-auto flex w-full max-w-md flex-col gap-6">

          {children}
        </section>
      </div>
    </main>
  )
}
```

**Copy:** composition through `children`/`Outlet`, semantic `<main>`, real `<Link>`, and route-entry `h1` focus. Extract the outer concerns instead of duplicating them.

**Required ownership:**

- `MobileFrame`: the only `100dvh`, flex-column and outer `overflow-hidden` owner; desktop breakpoint changes only frame chrome.
- `PageScrollArea`: the only `flex-1 min-h-0 overflow-y-auto` main-scroll owner; accepts a stable `id` for the skip link.
- `PublicAuthLayout`: brand link for entry pages or deterministic back link for step pages, then an `Outlet`; never shows Tabs.
- `AppShell`: skip link + main scroll + `BottomNavigation` as flex siblings; no `position: fixed` to browser viewport.
- `DetailLayout`: `AppHeader` + main scroll; no bottom navigation.
- `AppHeader`: real link to `/app/me`, 44×44 target, `aria-label="返回我的"`, truncated title.
- `BottomNavigation`: `nav aria-label="主要导航"`, four real `NavLink end` entries in locked order/icons. Let React Router provide `aria-current="page"`.

**Pitfalls:** child pages must not retain `min-h-dvh`; internal content must not use viewport `md:` layout changes because desktop still contains a 430px H5. Do not add a second `<main>` under `PageScrollArea`.

**No direct analog:** the codebase has no bottom navigation or single-scroll shell. Use the concrete structure in `01.1-RESEARCH.md:203-217` and `01.1-UI-SPEC.md` rather than improvising fixed positioning.

### Session Query/Mutation: `SessionList.tsx`, `RevokeSessionDialog.tsx`

const sessionsQuery = useQuery({

})
const revokeMutation = useMutation({

## Shared Patterns

### Authentication authority

**Source:** `AuthProvider.tsx:45-75`, `85-120`  
**Apply to:** all `/app/*` routes and session pages.

The browser identity is established only after `/users/me`; refresh is single-flight; an authenticated request replays once after 401. Layouts and pages consume `useAuth`, never decode JWT, persist token or call refresh independently.

### Error boundaries by distance

**Source:** `LoginPage.tsx:59-91`, `RegisterVerifyPage.tsx:79-111`  
**Apply to:** all authentication forms.

Field errors are attached to the field; network/server errors are top-of-form Alerts; recovery is an explicit retry/link; success is a target-page status. UI migration changes components/classes, not error classification.

### Server-state ownership

**Source:** `SessionList.tsx:22-41`  
**Apply to:** sessions details only.

TanStack Query owns session data and invalidation. Do not mirror it into an app context or local array.

### Semantic theme

**Source:** `styles.css:3-49`, `components/ui/button.tsx:6-40`  
**Apply to:** every new/modified component.

Semantic tokens are the only color API. Official shadcn/Base UI primitives are the only input/button/alert/dialog base.

### Route-entry focus and native semantics

**Source:** `PublicPages.tsx:10-32`, `components.test.tsx:59-82`  
**Apply to:** layouts, pages, navigation and dialog.

Focus the new page `h1`, use native link/button/nav/main semantics, keep dialog focus containment/restoration, and never use clickable `div`s.

### Directory documentation

**Source:** `frontend/src/auth/README.md:14-38`  
**Apply to:** `src/layouts/`, `src/app/`, snapshot directory and all parent indexes.

Every new directory is created with a README stating responsibility, allowed dependencies and complete file index. File moves/role changes update `src/README.md`, `auth/README.md`, `tests/e2e/README.md` in the same implementation task.

## Executor Pitfalls to Preserve

1. Do not touch backend API, schemas, migrations or database fields; current contracts already supply all data.
2. Do not add npm dependencies, reinitialize shadcn or introduce a second component library.
3. Do not keep `min-h-dvh` inside migrated pages; it creates two scroll owners under `MobileFrame`.
4. Do not use `position:fixed` for bottom navigation; keep it a non-scrolling sibling inside the frame.
5. Do not use Tab `replace`; only `/app` index redirect and login completion replace history.
6. Do not use `navigate(-1)` as the only detail/step return behavior; direct deep links need deterministic targets.
7. Do not broaden `returnTo` with prefix matching.
8. Do not rewrite AuthProvider refresh/logout/token behavior during a visual migration.
9. Do not treat `sessions=[]` as the healthy “only current device” state.
10. Do not mask whole cards or use mocked API in visual E2E; only dynamic date text may be masked.
11. Do not auto-update snapshots in normal test scripts.
12. Do not forget README/index updates when creating `app/`, `layouts/` or snapshot directories.
