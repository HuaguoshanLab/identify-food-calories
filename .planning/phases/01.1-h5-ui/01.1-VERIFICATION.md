## 要修复的缺口

### G-01：注册验证码 action 的失效上下文恢复

**影响：** 用户在验证码提交或重发后遇到已失效 context 时不能进入正确的“返回注册”恢复路径。  
**修复：** 去除 shadowed state，并分别测试 submit/resend 的 `VERIFICATION_CONTEXT_INVALID`。

### G-02：密码重置错误分类

**影响：** 用户会把暂时网络/服务问题误解为恢复链接已失效。  
**修复：** 只把真实 context 失效、过期、次数耗尽映射到重新申请；其余在顶部显示网络/服务错误并可重试当前流程。

### G-03：受保护路由标题焦点

**影响：** 键盘和读屏用户切换“我的”及两个详情页时不会收到新页面标题。  
**修复：** 新增可复用 heading-focus hook，或在 `MePage`/`AppHeader` 以 ref + `tabIndex={-1}` + effect 聚焦，并补齐路由级断言。
