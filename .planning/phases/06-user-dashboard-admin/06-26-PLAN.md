<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Authenticated JWT → `AdminService` | JWT 只能标识请求者；当前 active admin 角色必须由 PostgreSQL 在每次 command 中重新读取。 |
| Idempotency-Key → catalog resource projection | 已知 key 是不可信输入，不能授予读取既有 draft/publication 的能力。 |
| Agent snapshot → PlanPage | 运行时校验后的安全 status/message 才能进入用户 UI。 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-06-26-01 | E | catalog create/patch/publish/disqualify replay | mitigate | 在所有 replay lookup/return 前调用 `require_role`，并测试 normal/demoted actor 的 403。 |
| T-06-26-02 | I | PlanPage terminal error | mitigate | 只呈现 strict snapshot 的安全 message；回归禁止 provider/node/reasoning/raw payload。 |
| T-06-26-03 | T/R | catalog transaction and audit | mitigate | 保留现有 request-hash、单次提交、锁、immutable publication 与 audit-count 成功 replay 合同。 |
| T-06-SC | Tampering | npm/pip/cargo installs | accept | 不新增或安装任何依赖。 |
</threat_model>
