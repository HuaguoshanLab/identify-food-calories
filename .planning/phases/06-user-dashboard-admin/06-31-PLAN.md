## Trust Boundaries

| Boundary | Description |
|---|---|
| browser timezone → records confirmation API | 浏览器可声明 IANA string，但只有后端 ZoneInfo 验证并持久化的 preference 能定义 dashboard。 |
| confirmation response → dashboard reads | 200/known 409 是读取 gate；未知/错误 response 不得使页面把 UTC/空数据当成功。 |
| local calendar serialization → weekly API | `week_start` 是 untrusted request input；前端需要避免 UTC conversion bug，后端 06-30 仍是 Monday/current-week 最终验证者。 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-06-31-01 | T/E | client timezone authority | mitigate | 浏览器 zone 仅 POST 到既有 confirmation；dashboard reads 不传 zone，409 不覆盖已确认 preference。 |
| T-06-31-02 | I | H5 error/state | mitigate | 只显示安全、可恢复文案；不暴露 HTTP detail、provider、stack、token、preference internals 或健康敏感数据。 |
| T-06-31-03 | D | failed confirmation | mitigate | 失败关闭 dashboard queries 并提供 retry；不以 UTC、host timezone 或伪造零值继续。 |
| T-06-31-04 | T | Monday/DST serialization | mitigate | deterministic local-calendar tests覆盖 Shanghai、Los Angeles/DST；禁止 `toISOString()`/UTC getter/固定 offset。 |
| T-06-SC | Tampering | npm/pip/cargo installs | accept | 复用现有 React/Vitest/Playwright 与浏览器 API，不新增依赖。 |
