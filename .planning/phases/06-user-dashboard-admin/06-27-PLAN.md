## Trust Boundaries

| Boundary | Description |
|---|---|
| Public auth identity → admin SPA | `/users/me` 证明认证和 active 状态，不能授权后台。 |
| In-memory Bearer → `/api/v1/admin/probe` | 后端从 PostgreSQL 读取当前角色；前端只据其提供 UX。 |
| Admin Query cache → identity change | 旧身份的后台数据不得留给下一身份或 forbidden 页面。 |
