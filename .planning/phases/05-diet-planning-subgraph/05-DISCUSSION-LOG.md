## 身体资料与目标设定

| 决策 | 备选 | 选择 |
|---|---|---|
| 首次输入 | 最少字段并估算 / 完整身体资料、目标速度与偏好 | 完整填写 |
| 活动水平 | 三档 / 五档并配例子 / 自动换算 | 五档并配例子 |
| 目标速度 | 任意输入 / 保守预设并拒绝超范围 / 模型判断 | 保守预设并拒绝超范围 |
| 既有资料与偏好 | 不读取 / 自动套用 / 预填、展示、可编辑 | 预填、展示、可编辑 |

**User's choice:** 身高、体重、年龄、性别、活动水平、目标、目标速度、忌口与口味偏好均为首次规划必填。目标速度使用保守预设。长期资料可预填，但必须在生成前展示并允许编辑。

## 一日餐单呈现

| 决策 | 备选 | 选择 |
|---|---|---|
| 默认布局 | 全天总览 / 三餐卡片 / 单一时间线 | 三餐卡片加全天总览 |

## 用户反馈后的调整

| 决策 | 备选 | 选择 |
|---|---|---|
| 默认调整范围 | 局部替换 / 重生整天 / 仅建议不校验 | 局部替换 |
| 反馈记忆 | 仅当前计划 / 自动写入长期偏好 / 永不写入 | 自动写入长期偏好 |
| 更新展示 | 直接展示变化与校验 / 先选候选 / 静默替换 | 直接展示变化与校验 |
| 无严格替代项 | 询问放宽 / 自动放宽营养目标 / 目录外自由推荐 | 自动放宽营养目标并标明偏离 |
| 重排上限 | 一次 / 三次 / 无上限 | 三次 |

**User's choice:** 反馈只影响直接相关菜品；明确反馈自动形成长期偏好。系统可在无严格替代项时放宽热量或宏量目标，但必须透明呈现；同一线程至多重排三次。

## 健康安全边界

| 决策 | 备选 | 选择 |
|---|---|---|
| 高风险拒绝范围 | 仅治疗和用药 / 完整高风险范围 / 用户确认后继续 | 完整高风险范围 |

| 偏好管理 | 个人资料 / 记忆页 / 两处皆可 | 记忆页 |

**User's choice:** 拒绝疾病、用药、孕哺、未成年人、进食障碍、自伤和极端目标的个性化计划；身体资料与目标由“我的 → 个人资料”管理，忌口与口味偏好仍在记忆页。
