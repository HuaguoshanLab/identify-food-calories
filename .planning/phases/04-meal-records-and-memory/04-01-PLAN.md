<objective>
建立餐食记录与长期记忆的 PostgreSQL 权威账本，并交付只能从完成 Agent 报告显式确认保存的餐食记录 API。

Purpose: 保证报告不会自动变成历史数据，营养快照可追溯且永不被目录升级静默重写，为记忆审计和删除链提供本地授权事实。
Output: 独立 records 领域模块、Alembic `0007`、餐食记录 REST 契约和真实 PostgreSQL 覆盖。
</objective>
