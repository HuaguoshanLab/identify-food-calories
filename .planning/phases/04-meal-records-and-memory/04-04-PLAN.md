<threat_model>
| Threat | Mitigation | Verification |
|---|---|---|
| 前端伪造营养/保存状态 | client 仅发送 thread/command/time；成功 API 后才显示已保存 | component + API contract tests |
| 删除误触或状态泄露 | DetailLayout 危险区 + AlertDialog + 安全“已删除”反馈 | keyboard/focus component test |

| UI 读取跨用户/内部敏感字段 | safe DTO Zod schema + authenticated API only | response schema and E2E access tests |
</threat_model>
