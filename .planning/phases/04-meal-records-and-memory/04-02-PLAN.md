<threat_model>
| Threat | Mitigation | Verification |
|---|---|---|
| Mem0 external ID 越权 | 本地 ledger `(id,user_id,active)` 先授权，adapter 不暴露裸 ID API | provider spy + 双用户 tests |
| 模型把推测伪装成事实 | source_kind + pending/confirm gate + whitelist | fake provider call assertions |
| 外部删除失败导致旧偏好再被推荐 | transaction 先停用检索并写 outbox；worker 只做最终清理 | first-delete-fails integration test |
| 密钥/原文泄露 | Pydantic settings、最小 DTO、安全日志/response | config and response contract tests |
</threat_model>
