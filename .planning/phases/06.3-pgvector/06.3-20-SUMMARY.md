# Phase 06.3 Plan 20: Hybrid Food Search Acceptance Summary

补齐混合菜品检索的中文可复现指南、真实后台 E2E 合同和只在隔离测试应用启用的受控 Fake embedding outcome 脚本；没有把 Langfuse 或真实 Provider 变成发布依赖。

## Completed Work

- 新增中文教学文档：精确优先、非精确 `ASK`/resume、current-qualified 检索、publication 聚合/retry、worker lease、证据绑定 activation、Phoenix/Langfuse 边界、30 天留存、启动/调试/冻结评测命令和常见错误。

- 由于原 Fake 没有可由真实 HTTP 应用配置的 outcome，新增最小 Rule 4 修复：`TEST_EMBEDDING_OUTCOMES` 仅在 `APP_ENV=test` 允许 `success`/`permanent_failure` 闭集；Factory 只给 test Fake 排队离线结果，默认无配置行为仍为 `FAKE_UNSCRIPTED_CALL`，local/production 传入变量直接 fail closed。
- 为用户可见且不读取 token 的 status-GET RBAC 验收增加“刷新嵌入构建状态”按钮；两个先真实登录为管理员、再由另一个管理员降权的独立浏览器会话分别从页面触发 GET 403 与 POST 403。

## Deviations from Plan

### Approved Architectural Correction

1. **[Rule 4 - Test-only Fake outcome injection]**
   - **Found during:** Task 1 E2E implementation。
   - **Issue:** 测试应用的 `FakeEmbeddingProvider` 默认所有未脚本调用均永久失败，公开目录发布无法同时获得 completed 与 failed job，不能生成真实 `partial_failure`。
   - **Fix:** 增加只接受 `success`、`permanent_failure` 的 test-only Settings/Factory/Fake seam，并由 Playwright test backend 环境显式配置 `success,permanent_failure,success`。
   - **Safety:** 非 test 环境含该变量即拒绝启动；不能传入 Provider body、回调、名称或任意错误码；默认 Fake 行为未改变。
   - **Authorization:** Parent executor explicitly approved Rule 4。

2. **[Rule 2 - User-visible status refresh]**
   - **Found during:** Task 1 RBAC browser-path design。
   - **Issue:** 现有页面自动初读状态，普通用户收到状态 GET 403 后无法再从页面触发 retry；也没有可见方式重读 status endpoint。
   - **Fix:** 增加不携带额外数据的“刷新嵌入构建状态”动作，并以两个真实已降权会话分别验证 GET 与 POST 边界，避免 token 复制/注入。
