补齐混合菜品检索的中文可复现指南、真实后台 E2E 合同和只在隔离测试应用启用的受控 Fake embedding outcome 脚本；没有把 Langfuse 或真实 Provider 变成发布依赖。

## Deviations from Plan

### Approved Architectural Correction

1. **[Rule 4 - Test-only Fake outcome injection]**
   - **Found during:** Task 1 E2E implementation。
   - **Issue:** 测试应用的 `FakeEmbeddingProvider` 默认所有未脚本调用均永久失败，公开目录发布无法同时获得 completed 与 failed job，不能生成真实 `partial_failure`。
   - **Fix:** 增加只接受 `success`、`permanent_failure` 的 test-only Settings/Factory/Fake seam，并由 Playwright test backend 环境显式配置 `success,permanent_failure,success`。
   - **Safety:** 非 test 环境含该变量即拒绝启动；不能传入 Provider body、回调、名称或任意错误码；默认 Fake 行为未改变。
   - **Authorization:** Parent executor explicitly approved Rule 4。

2. **[Rule 2 - User-visible status refresh]**
   - **Found during:** Task 1 RBAC browser-path design。
   - **Issue:** 现有页面自动初读状态，普通用户收到状态 GET 403 后无法再从页面触发 retry；也没有可见方式重读 status endpoint。
   - **Fix:** 增加不携带额外数据的“刷新嵌入构建状态”动作，并以两个真实已降权会话分别验证 GET 与 POST 边界，避免 token 复制/注入。

3. **[User-authorized pre-existing dependency repair]**
   - **Found during:** Task 1 Playwright startup。
   - **Issue:** `frontend/package-lock.json` 缺少现有 package graph 所需的 `gcp-metadata@7.0.1` 解析记录，`npm ci` 拒绝安装。
   - **Fix:** 用户明确授权后仅以 lockfile-only 模式同步，并以 `npm ci --ignore-scripts` 验证；未更改 `package.json`、未新增或升级产品依赖。
   - **Commit:** `a16d61c`。

4. **[User-authorized minimal operational lookup]**
   - **Found during:** built-in browser activation setup。
   - **Issue:** approved controlled CLIs required an opaque UUID, but the public administrator page deliberately does not display it; copying a token or writing the database would violate the browser contract.
   - **Fix:** `vector-build` and activation CLI now accept mutually exclusive `--actor-user-id` or `--actor-email`. Email only resolves the local account to its UUID, then `AdminService` rechecks persisted RBAC and stores the UUID in audit evidence.
   - **Safety:** no HTTP/UI endpoint, token path or direct database mutation was added.
