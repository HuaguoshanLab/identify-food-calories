# Phase 06.3 Plan 21: Vector Space Build Summary

管理员现在可以以固定模型、1024 维度、adapter 和 retrieval 版本创建可重放的向量空间 build；同一命令只冻结一次当前 eligible 目录名称快照并只入队一次。

## Delivered

- 新增 `POST /api/v1/admin/vector-space-builds`，要求数据库重新确认的管理员角色、确认字段和 `Idempotency-Key`。
- 在 PostgreSQL advisory lock 的单一事务内创建/复用 immutable vector space，按稳定顺序冻结当前 eligible canonical/controlled alias 的 publication、search-version 和 name ID 清单，写入 SHA-256 hash、任务与 append-only 审计。
- `0026_vector_space_retrieval_identity` 将 retrieval version 加入非空 vector-space/build identity，并把 unique key 扩展为 model/dimension/adapter/retrieval；已有 0025 数据明确回填为当时唯一部署的 `hybrid-v1`。
- 相同键重放返回同一 build；模型、维度、adapter、retrieval 版本、管理员或原因不一致时闭合拒绝。
- 响应只提供空间 identity、manifest hash 和计数；没有受控名称、向量、provider body、完成证据或 activation 副作用。

### Approved Architectural Correction

真实 PostgreSQL fixture 包含既有 eligible catalog 数据，因此断言验证新 publication 三个名称被精确纳入且全局 name ID 唯一，而非错误假设数据库中只有三个 eligible 名称。
