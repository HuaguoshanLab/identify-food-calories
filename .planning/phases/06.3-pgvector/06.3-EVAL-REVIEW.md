## Critical Gaps

当前没有 MISSING 维度，也没有已证明未实现的在线安全拦截。上一版的关系标签端到端 blocker 已关闭。

但不要把“没有 blocker”误读为“可跳过后续工作”：下列 Partial 项直接限制了生产可观测性和评测数据治理，因此总分仍为 NEEDS WORK。

## Remediation Plan

### Must fix before production:

1. 为冻结集新增或修改的 relation、排除项和高后果 exact/similar 判断保存版本化审核 artifact：目录管理员、营养师、中文菜系专家和隐私负责人各自的确认、日期、dataset hash 与版本。没有该证据不得替换冻结标签。
2. 为 allowlist 拒绝和 DTO invariant 失败发出不含 payload 的 `error.code` 与可路由计数/告警；按 retrieval/catalog/vector-space 版本聚合并对语义降级率、零候选率、确认后失效、索引滞后和预算/任务耗尽配置 AI-SPEC 阈值。

### Should fix soon:

1. 在 release 或独立性能证据中记录 exact、text fallback、hybrid 的终态耗时，按 p50/p95/p99 对 50ms、150ms、1.5s 初始 SLO 做明确 PASS/WARN/FAIL；在目标区域校准后版本化阈值。
2. 在本地隔离 Langfuse 实际执行一次合成 frozen Experiment publish，30 天 purge + requery 验证；保存仅含 hash、计数、状态和日期的无 payload 证据，确认其不影响 release 决策。
3. 增加负向 frozen 合同，显式篡改 relation label 分布、关系层顺序和一个 graph 入口的 selected/candidate/relation 任一字段，保持 release rehash 后仍必须 FAIL（当前已覆盖 graph 输出漂移；应扩大为三种关系专门回归）。

### Nice to have:

1. 建立 nightly frozen-suite 与不可覆盖的失败历史归档；生产信号只能由人工转写为合成案例。
2. 为共享单一食材负例、候选不足 3 条和多候选跨层排序增加经审核案例，扩大中文地域菜式覆盖。
