# Phase 06.3 Plan 19: Langfuse Detailed Experiment Retention Summary

提供一个独立、显式、无持久报告的 Langfuse 30 天详细实验记录清理命令；删除请求与异步回查均受严格上限约束。

## Completed Work

- 新增 `langfuse_retention.py purge --older-than 30d --verify --format json`：仅清理 `phase063.frozen_case` trace，使用固定 UTC 边界，批量调用官方 trace 删除 API，并回查至确认完成。
- trace 删除由 Langfuse 级联到关联 observations 和 scores；命令不读取、输出或存储 trace payload，也不根据 PASS/FAIL、分数或任何用户/餐食数据选择记录。
- stdout 只输出精确六字段 JSON：`cutoff_utc`、`scanned`、`requested`、`verified_deleted`、`remaining_overdue`、`status`；失败 stderr 只输出安全码并返回非零。
- 补齐 29/30/31 天边界、PASS/FAIL 对称、分页、批量、异步延迟、无法验证、页数上限和 CLI JSON 合同测试；README 明确手工执行和无 artifact 约束。
