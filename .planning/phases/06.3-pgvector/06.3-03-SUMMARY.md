# Phase 06.3 Plan 03: DashScope Embedding Provider Summary

**Pinned DashScope `text-embedding-v4`/1024 adapter with offline-test isolation, validated cost/timeout settings, and explicit text-only fallback.**

## Accomplishments

- Added one bounded HTTPX adapter for the fixed DashScope HTTPS embedding endpoint; it retries only one 429/5xx response and maps failures to body-free stable error codes.
- Added `EmbeddingProviderMode` and production validation for API key, pinned model/dimension, adapter and price versions, 1.5-second timeout, and positive cost caps.
- Added a deterministic factory: tests always receive Fake, production rejects Fake/disabled modes, and local text-only fallback is explicit.
- Added MockTransport coverage for factory selection, timeout, status, retry count, vector count/dimension, NaN/Infinity, cost calculation, and response-body non-leakage.
