# Phase 06.3 Plan 06: Authoritative Hybrid Repository Summary

**PostgreSQL is now the single authority for exact, pg_trgm and pgvector food candidates and for final confirmation rereads.**

## Accomplishments

- Added `SqlAlchemyHybridFoodSearchRepository` with bound exact, text-similarity and cosine-distance queries, bounded result pools and stable SQL tie-breakers.
- Extracted the current publication qualification predicate into the existing nutrition repository so legacy lookup, all retrieval channels and confirmation use the same active, eligible, calculable, sourced record boundary.
- Vector retrieval only accepts finite 1024-dimensional inputs and joins the active vector-space pointer; a missing active/ready index safely produces no vector candidates while unrelated SQL errors still propagate.
- Text relation projection only accepts active controlled evidence whose source and target search versions both match their current publication content hashes; absent evidence stays conservatively labelled `同类食物`.
- Added real PostgreSQL coverage for exact lookup, current confirmation, trigram and cosine results, rank ordering and bounded `EXPLAIN (ANALYZE, BUFFERS)` evidence.
