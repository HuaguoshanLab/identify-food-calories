# 06.2-02 Summary：系统管理后台 UI

后台新增一级“系统管理”，二级为“管理员管理”和“角色管理”。管理员页支持全量邮箱展示、邮箱/角色/状态筛选、分页、升降权确认和原因；角色页只读展示固定 `admin/user` 权限与账号数，不伪装成动态权限系统。
