## 后台账号可见范围

| Option | Description | Selected |
|--------|-------------|----------|
| 仅展示管理员 | 新增管理员时只通过精确邮箱查找目标账号，最小化普通账号曝光。 | |
| 展示全部账号 | 管理员可查看全部账号及邮箱，并按角色和状态筛选。 | ✓ |

**User's choice:** 可以暴露全部账号。
**Notes:** 仅扩大管理员所需身份字段；不得借此返回会话、密码、健康或餐食数据。

## 降权后的会话处理

| Option | Description | Selected |
|--------|-------------|----------|
| 保留普通用户会话 | 立即撤销后台访问，但现有用户端会话继续有效。 | ✓ |
| 强制退出全部会话 | 降权同时撤销用户端登录，影响正常用户功能。 | |

**User's choice:** 保留。
**Notes:** 后台每个请求重查数据库角色，因此无需依赖强制退出才能让旧 token 失去后台权限。
