# H5 全局视觉样式

## 设计决策

- 采用设计稿森林绿 CTA、浅绿灰页面、白色卡片和深绿黑正文。
- 系统中文无衬线字体，不新增远程字体或依赖；正文和控件保留 16px 基准，具体标题重排留到页面项。
- 基础圆角 8px，卡片派生 12px；阴影统一为低透明度绿灰。
- 小字及状态颜色按实际对比度微调；不机械复制不满足可读性的参考值。
- UI 技能生成的通用下载页、青色与远程字体建议不适用于已冻结参考；仅采用可访问性、减少动效等校验原则。
- 页面壳、导航高度、各页面卡片结构和公共组件行为留到后续项。
