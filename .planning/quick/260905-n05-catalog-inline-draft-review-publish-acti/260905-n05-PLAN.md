# 营养目录表格入口与居中弹窗保存、审核、发布

1. 用户后续明确改为居中弹窗：新增/编辑统一中央表单，底部提供保存草稿。直接提交前仍请求服务端预览，以保留版本及校验边界；取消二次预览弹窗。
2. 行操作增加审核、发布，打开居中的精简确认弹窗。先取服务端生命周期投影，保留默认折叠的字段差异；不伪造审核状态，不跳过后端授权/审核/审计。失败在当前弹窗显示；重试复用相同命令键。
3. 测试保存、取消、审核/发布成功、未授权、409及401/403；运行类型检查、构建和内置浏览器交互验证。更新索引与 STATE，不改 ROADMAP。

范围：仅前端交互。旧详情页保留兼容，CSV 导入共享的窗口也统一居中，导入逻辑不变。保留已有未提交 debug 文档，不纳入本次提交。
