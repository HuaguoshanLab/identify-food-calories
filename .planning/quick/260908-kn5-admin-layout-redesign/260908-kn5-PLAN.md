# 后台管理页面壳改版

将独立 `admin-frontend` 的页面壳重构为固定深色侧栏、可折叠分组菜单、顶部面包屑、多页面标签和窄屏覆盖式抽屉。只调整布局及展示交互，不改变后台 API、运行时 token 或 DB RBAC 边界。

## Task 1：拆分并重构页面壳

- 新增共享菜单配置、侧栏、顶部栏和标签栏组件。
- 桌面端固定侧栏支持完整与图标态；小于 1024px 使用覆盖式抽屉，不挤压内容区。
- 标签跟随路由创建、切换和关闭，运行概览固定不可关闭。

## Task 2：统一视觉和文档

- 使用深色导航、浅色内容、绿色强调色和一致的 Lucide 图标。
- 更新布局及样式目录索引，不引入第二套依赖或远程字体。

## Task 3：验证

- 运行布局组件测试、后台完整单测、类型检查和生产构建。
- 通过真实浏览器验证桌面导航、二级菜单、标签切换和移动抽屉。
