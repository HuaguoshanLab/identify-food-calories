# 营养目录与菜谱候选导入批次

本目录保留从项目原始数据整理出的可导入 CSV，不修改 `菜品/` 下的原始文件。

## 导入顺序

1. 在后台 **营养目录** 依次导入以下 5 个文件：
   - `食材营养目录-导入批次1.csv`
   - `食材营养目录-导入批次2.csv`
   - `食材营养目录-导入批次3.csv`
   - `成品菜营养目录-导入批次1.csv`
   - `成品菜营养目录-导入批次2.csv`
2. 在营养目录审核并发布全部 5 批。
3. 在后台 **菜谱管理** 依次导入以下 2 个文件：
   - `菜谱候选-导入批次1.csv`
   - `菜谱候选-导入批次2.csv`
4. 菜谱候选导入后的状态为“待审核”；确认内容后批量启用，餐单生成才会使用它们。

| 文件 | 导入位置 | 职责 |
|---|---|---|
| `食材营养目录-导入批次*.csv` | 营养目录 | 食材营养数据；每批不超过 500 条。 |
| `成品菜营养目录-导入批次*.csv` | 营养目录 | 成品菜营养数据；每批不超过 500 条。 |
| `菜谱候选-导入批次*.csv` | 菜谱管理 | 餐次、份量和标签；按已发布的成品菜营养目录建立关联。 |

同名冲突已按“使用成品菜目录能量”处理，重复别名已编号。两份菜谱候选共 612 条已核对可与当前已发布目录唯一关联。
